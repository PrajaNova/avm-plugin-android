# avm-plugin-android

avm's native Android SDK provider — version listing (live from Google's
`repository2-3.xml`), cmdline-tools/sdkmanager-driven install, and
`ANDROID_HOME`/`ANDROID_SDK_ROOT` resolution, for
[avm](https://github.com/PrajaNova/avm).

Speaks avm's plugin protocol, documented in the main repo.

```bash
cargo build --release
# binary at target/release/avm-plugin-android
```
